# Animal Health Monitoring Device

## Overview
The Animal Health Monitoring Device is an IoT-based system that monitors an animal's body temperature, activity, and battery level in real time. It detects abnormal conditions and displays the data on a web dashboard.

## Features
- Real-time temperature monitoring
- Activity monitoring using MPU6050
- Battery voltage monitoring
- Wi-Fi dashboard
- Health status alerts
- ESP32-based system

## Components Used
- ESP32
- DS18B20 Temperature Sensor
- MPU6050 Accelerometer
- Battery Module

## Programming Languages
- C++
- HTML
- CSS
- JavaScript
